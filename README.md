Um organizador financeiro e documental completo para a Declaração de Imposto de Renda Pessoa Física (IRPF), desenhado para facilitar a recolha, estruturação e conferência de dados fiscais de forma prática e visualmente agradável.

---

## 🌸 Sobre o Projeto

O **Organizador IRPF** foi desenvolvido para resolver a desorganização comum no período de prestação de contas com a Receita Federal. O projeto conta com uma versão interativa em **HTML/CSS/JS** e uma versão automatizada em **Planilha Excel (`.xlsx`)**, ambas personalizadas com uma estética *Coquette / Soft Pink* delicada (tons de rosa pastel, cartões arredondados e ícones temáticos 🎀).

---

## ✨ Funcionalidades Principais

- **👤 Dados do Titular:** Registo centralizado das informações pessoais (CPF, Título de Eleitor, Endereço, Cônjuge e estatuto de residência no exterior).
- **🏦 Informes de Rendimentos Bancários:** Cartões dedicados por instituição bancária com campo para valor atual, nome do anexo do comprovativo e soma automática do total acumulado (`=SUM(...)`).
- **📜 Histórico de Holerites & Entradas:** Tabela para registo mensal de receitas, holerites e notas fiscais com formatação automática de moeda (`R$`) e datas.
- **🏛️ Validação de Dados & Tabela de Bancos:** Menu suspenso (*Data Validation*) pré-carregado com mais de 50 instituições financeiras e respetivos códigos bancários oficiais.
- **🎨 Estética Personalizada:** Layout estilizado em tons de rosa suave (*Lavender Blush* / *Rose Pastel*), combinando funcionalidade técnica com um design fofo e organizado.

---

## 🛠️ Tecnologias Utilizadas

- **Microsoft Excel / openpyxl:** Formulação de dados, validação de entradas, formatação condicional e personalização de estilos.
- **Python:** Script de automação e geração da estrutura XML/XLSX.
- **HTML5 / CSS3 / JavaScript:** Interface web responsiva para navegação local.
